VARNA LIQUID48 - PACKAGE LAYOUT REPAIR

Close After Effects.
Extract this ZIP as a NEW subfolder inside your OLD extracted Varna package.
Open the new subfolder and run REPAIR_AND_INSTALL_WINDOWS.bat.
Choose installation level 1, 2 or 3.

There is no folder merging or file replacement step.
This utility uses the original complete asset library. It verifies sources,
reuses the existing verified component, prepares a complete sibling package,
and runs the actual native installer from there. Source files are preserved.
If asked to choose a folder, select the original extracted base package.
