VARNA Production47 - Installer recovery patch 1

This is a small patch for the already extracted Production47 archive.
It is NOT a complete plugin package.

1. Close After Effects.
2. Extract this patch ZIP.
3. Copy the CONTENTS of the extracted patch folder into the original
   Varna-Motions-Studio-4.5.0-rc.47-production47 folder, beside the existing
   PREPARE_GITHUB_DOWNLOAD.ps1. Replace files and merge the plugin folder.
4. Run INSTALL_WINDOWS.bat from that main folder, then choose 1, 2, or 3.

Keep all original package files. The required 147 MB component will be
verified and restored automatically. A new verified download is retained
if replacement fails, so the next retry can reuse it.

Includes a matching package manifest. Do not disable checksum validation.
