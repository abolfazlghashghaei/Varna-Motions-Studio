# Studio52

Base: Studio51 (`5ca5219`). Primary AE adapter revision `rc47.5`, package version still `4.5.0-rc.47`. This is a development prerelease, not a native-host parity claim.

Implemented: direct studio entry; browser popup handoff of a validated project and File blobs with source/origin/nonce checks; fullscreen; shared graphic layers and timeline; independent shape Size, keyframes/curves, entry presets, table surfaces/dividers/imported merges; canvas glass approximation; transforms/blending/ellipse masks/fades/blur/exposure; graphic split/duplicate/delete; physical-key shortcuts; protected-content localization with RTL/LTR; independent local text review/translation and audio pipeline; frame-sequence ProRes4444 alpha export; separate Premiere CEP and Resolve utility packaging.

The native AE renderer receives new graphic layers inside the existing owned-composition transaction. Size/position/scale/rotation/opacity curves are sampled per frame; width/height share combined values so animation does not reset the other axis or corner roundness. New native footage supports rotation, ellipse mask, blend and fades. Unsupported native transfer of animated grading or certain animated tables rejects with an explicit render requirement. Original user compositions/items are not rewritten. Native color/optical effects can differ from Canvas.

Premiere uses its own manifest/entry/ES3 adapter and strict no-eval JSON fallback. MOGRT insertion uses SDK ticks and video-track offsets; transparent MOV uses video-track insertion. Occupied destination ranges are rejected. No subtitle track API is used. AE can export editable MOGRT from a newly built graphics composition when the project is saved. Resolve inserts a new Fusion composition and pastes an exported Text+ setting containing text/color/rounded background/fade; default duration must be trimmed by the editor. The utility does not promise automatic exact duration or parity with AE animation.

Cross-host installation checks source hashes before staging; Premiere installs only the editor code, logo and integration files, with an owned backup, and does not copy native AE plugin binaries. Resolve installs its own backed-up script only. Source dependency/compatibility information lives in `integrations/effects/COMPATIBILITY.json`; original vendor notices remain in Info. Windows PowerShell/native application activation is untested here.

English localization covers the studio, primary navigation and shared controls; older technical copy/statuses can remain Persian. It never changes project values, captions, media names or brand identity. UI tests found and corrected an overbroad language-button selector that initially matched the body. No claim of complete catalog translation is made.

Local AI reuses the existing GHAFNode and music-engine policy. It validates caption ids/JSON, requires explicit approval, retains style/instrument/model choices, rejects detected vocals/silence/short output and converts accepted audio to a real PCM WAV. Its service is loopback/token/Origin protected and shares the single-job boundary. Tests use controlled model responses; actual Qwen/Whisper/music inference and subjective audio quality are not tested.

Transparent export sends dimension-checked PNG frames to an owned, bounded local job, or renders via the existing CEP Node tools. FFmpeg creates ProRes4444 with alpha. It is tested using actual encoded output and alpha extraction. It is a graphics overlay: it cannot blur/refraction-sample a future host's underlying footage. Exact optical composite appearance requires a full video render. Cancelled/incomplete jobs do not produce a delivery file.

Tests: `studio52_core.cjs` validates transactions, width/height easing, native frame Size keys/roundness and the actual Premiere adapter against an SDK model with JSON absent and occupied-track rejection. `studio52_ai.cjs` validates known-caption/genre/instrument/voice/silence policy against controlled inference fixtures. `studio52_browser.cjs` covers actual pixels, protected Persian content in English mode, RTL/LTR, popup handoff, fullscreen, actual ProRes alpha and responsive widths. Existing Studio51 media/export/native-transfer regressions are retained.

Unfinished scope: complete Premiere/Resolve native runtime qualification; full language catalog; exact native AE binary/optical/effect parity; a complete replacement for the four requested professional editors; large-project/GPU performance qualification. These are not represented as delivered features.

Official API references inspected: docsforadobe Premiere sequence `importMGT`/`overwriteClip`, and AE `exportAsMotionGraphicsTemplate`. No third-party editor source or unsupported binary conversion is bundled.

Final recorded results: **94/94 release suites passed**; Studio52 real browser graphics/popup/fullscreen/localization/ProRes-alpha checks passed. The Studio51 real-media/export regression, previous Production50 typography/table/audio/brand checks and Finalize49 appearance/startup browser checks passed. The final package manifest verifies **3223 files**; all **21 AE host files** pass ES3 parsing and combined-source synchronization. Evidence is in `/workspace/artifacts/Studio52_*`. Native Windows/Adobe/Resolve execution and real model inference remain unverified.

The standalone launcher now defaults to fixed loopback port 8794 (override VARNA_EDITOR_PORT) so browser storage survives server restarts. An occupied port reports an explicit failure rather than silently changing origin. AI audio startup retains the engine's selected launch port and supports registering an external models folder.
