# تحویل UI77 — پنل افتر

رابط فایل ارسالی روی کنترل‌های واقعی پلاگین پیاده شد: خانهٔ پنج‌کاره، بخش‌های جمع‌شونده، ابزارهای قابل جست‌وجو، میانبرهای سنجاق‌شده و قابل جابه‌جایی، دکمهٔ اصلی ثابت، تم‌های قبلی و رنگ دلخواه، محوشدگی ذخیره‌شونده و همان V متحرک قبلی. تغییر روشنایی انتخاب رنگ را پاک نمی‌کند. نصب بدون موتور، میانبر خرابِ تولید صدا ندارد و اصلاح آفلاین و زیرنویس را نگه می‌دارد.

کد مرجع محصول: `af47debfb8871ae780997ec706119691f6a9c945`؛ گزارش و آزمون تکمیلی در commit همراه این فایل ثبت می‌شوند. منطق `host/` و ورودی‌های Premiere/Resolve تغییر نکرده‌اند؛ ادغام UI77 روی ورودی After Effects است.

|---|---|
| ماتریس ۲۲ صفحه × ۶ عرض × ۳ ارتفاع × ۴ مقیاس × ۲ تم × ۲ زبان | ۶۳۳۶ حالت، صفر شکست |
| همان ماتریس با محدودکردن قابلیت‌های بعد از Chromium 99 | ۶۳۳۶ حالت، صفر شکست |
| جدول و تایپوگرافی با تست اصلیِ پایلوت | ۵۷۶ حالت صفحه / ۸۶۴ حالت بازشده، صفر شکست |
| ارتفاع کوتاه و شش تنظیم اندازهٔ رابط | ۱۱۵۲ حالت در هر دو مسیر، صفر شکست؛ حداقل فضای خالص ۵۱٫۹۳٪ |
| تنظیمات پیشرفتهٔ صفحات دیگر | ۲۱۳ حالت، صفر شکست؛ چهار مسیر دو دستگیره‌ایِ اصلی صریحاً از هم‌پوشانی تصادفی جدا بررسی می‌شوند |
| `ui47_controls_browser`، `table47_browser`، `ui68_tokens_browser` و تعامل‌های `ui69` | پاس؛ فایل تست‌های قبلی دست‌کاری نشده‌اند |
| آزمون ادغام UI77 | هویت کنترل‌های اصلی، ۸۹۹ شناسه، فرمان اصلی واقعی، Undo، تم، روشنایی، blur، جابه‌جایی/بازنشانی میانبر، زبان، فوکوس، ذخیره و V پاس |
| پروفایل نصب بدون موتور | قطعهٔ واقعی تولیدشده توسط Profile60: ۲۱ صفحه، بدون میانبر مرده، بدون خطای مرورگر |
| Release gate اصلی | ۸۶ از ۱۰۰؛ دقیقاً همان ۱۴ شکستِ پایه، بدون شکست جدید یا تضعیف تست |

مرورگر واقعی این آزمون‌ها Chromium `154.0.8037.57` بوده است. محدودکردن قابلیت‌ها، اجرای بومی Chromium/CEF 99 محسوب نمی‌شود. جزئیاتِ شناسه‌ها، هش ثابت کد حین ماتریس، نتایج و لاگ‌ها کنار این گزارش هستند.

| معیار | قبل | بعد |

| شناسهٔ ثابت در هر HTML | ۸۹۹ | ۸۹۹ |

CSS تازه یک لایهٔ ارائهٔ مستند و محدود است؛ ادغام نهاییِ همهٔ CSSها یا حذف بی‌اثباتِ فایل قدیمی انجام نشده است. علت استثناهای `!important` در کد و [شرح ادغام](IMPLEMENTATION_FA.md) نوشته شده است. رنگ‌ها و اندازه‌های متنِ خروجی پروژه با تنظیمات رابط عوض نمی‌شوند.

## برای دیدن و آزمودن

[گالری قبل/بعد](GALLERY.html): ۱۷۶ جفت تصویر برای همهٔ ۲۲ صفحه، عرض‌های ۲۵۰، ۴۰۰، ۶۲۰ و ۱۴۰۰ و هر دو تم؛ به‌علاوه ۱۲ نمونهٔ رنگ. تصاویر مربوط به رابط مرورگر با دادهٔ آزمایشی هستند، نه رندر افتر.

[چک‌لیست ده‌مرحله‌ای](MANUAL_TEST_FA.md) شامل مواردی است که فقط روی دستگاه تأیید می‌شوند: نصب Windows، اجرای CEP داخل افتر، DPI ویندوز، فونت‌های واقعی، پیش‌نمایش/خروجی جلوه‌های بومی و موتورهای AI. این موارد در این محیط تست بومی نشده‌اند. ورودی‌های Premiere و Resolve نیز آزمون بومی جدا می‌خواهند.

بستهٔ Windows فایل‌های لازم را محلی با SHA-256 بررسی می‌کند؛ قطعهٔ مخصوص Mac در آن نیست و آماده‌سازی برای آن دانلود نمی‌کند. مدل‌های AI و موتور اختیاری همراه بسته نیستند. این تحویل برای آزمون رابط است؛ گزارش ۱۴ شکست قدیمی در [محدودیت‌های release gate](RELEASE_FAILURES_FA.md) آمده است.
