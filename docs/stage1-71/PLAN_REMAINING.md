# ترتیب اجرای درخواست نهایی

این سند، ترتیب قبلیِ «توقف بعد از هر دسته» را با درخواست تازه جایگزین می‌کند.

1. تکمیل پیش‌نیاز CEP 12 و ارتفاع کم؛ commit مستقل و توقف اجباری با گزارش.
2. پس از ادامهٔ کار، تعمیم همان کامپوننت‌های پایلوت به ۲۰ صفحه؛ هر دسته commit جدا، بدون توقف بین دسته‌ها:
   - خانه / خروجی / محدودهٔ امن.
   - متن / موشن / استایل‌ها / منحنی حرکت.
   - افکت صوتی / ساخت صدا / ساخت زیرنویس / کلمات مهم / ترجمه.
   - بکگراند / برند / دستیار پروژه / دستیار اسکریپت / اصلاح هوشمند / ابزارهای افزوده / منابع سیستم / تنظیمات.
3. ادغام لایه‌های CSS در tokens/base/components/pages؛ مستندکردن پوشش قواعد، تعداد important و تصاویر. حذف فایل قدیمی فقط با شاهد پوشش؛ stability26.css نگه داشته می‌شود مگر پوشش کامل ثابت شود.
4. توقف اجباری پیش از تغییر HTML مشترک: ارائهٔ اختلاف ورودی‌ها و ریسک اتصال هر میزبان. اجرای آن مرحله یا رد مستدل آن بعد از این نقطهٔ توقف مشخص می‌شود.
5. بررسی ۱۴ شکست پیشین release در commit جدا: رفع علت یا به‌روزرسانی مستدل آزمون منسوخ؛ بدون حذف یا تضعیف آزمون.
6. تحویل نهایی بعد از مراحل بالا: گزارش یک‌صفحه‌ای، فهرست commitها، گالری ۲۲ صفحه در چهار عرض و دو تم، راهنمای تست دستی ده‌مرحله‌ای و بستهٔ نصبیِ آمادهٔ آزمون.

در تمام مراحل: ۸۹۹ شناسهٔ ثابت، حفظ رفتار کنترل‌های عددی و منطق میزبان، ui47/table47/ui68 سبز و ماتریس کامل ابعاد/مقیاس/زبان/تم برای صفحه‌های تعمیم‌یافته. ادعای اجرای واقعی AE/Premiere/Resolve بدون دسترسی و شاهد ممنوع است.

وضعیت فعلی: فقط مرحلهٔ ۱؛ تعمیم ۲۰ صفحه، تمیزکاری CSS، HTML مشترک، اصلاح ۱۴ شکست و بستهٔ نهایی در این مرحله انجام نشده‌اند. commit سازگاری پیشین `23a8f28` حفظ شده و اصلاح ارتفاع در commit مستقل بعدی ثبت می‌شود. ارسال GitHub در این مرحله انجام نمی‌شود؛ commitها محلی هستند.
