# علت به‌روزرسانی آزمون‌های مسیر قالب

هیچ فایل از run-release.cjs حذف یا ضعیف نشده است. ui47، table47، ui68 و اوراکل سخت‌گیرانهٔ اندازه/برخورد همان‌اند. تغییرهای قرارداد زیر خواستهٔ صریح کاربر را می‌آزمایند:

- user_library81_browser: گالری قدیمیِ زیر ابزارها با مقصد مستقل نام‌نوشته‌ها جایگزین شده است. همان ۱۲ طرح نخست، بارگذاری بایت واقعی poster در صورت PRIVATE_LIBRARY81، payload ویرایش متن/کنترل و هشت چیدمان بررسی می‌شود. قبل از اعمال، import یا کد vendor نباید اجرا شود؛ بعد از اعمال همان مسیر واقعی آزموده می‌شود.
- library82_browser: انتخاب بسته دیگر نباید import کند. آزمون ابتدا پریویو و سپس Apply را می‌زند و همان payload ترنزیشن، DJ، Foil، استایل و بازگشت بک‌گراند را بررسی می‌کند.
- ui83_features_browser: فهرست عمومی ۱۹ ابزار اکنون هفت مقصد مستقل دارد. جست‌وجو، handler واقعی، حفظ draft، شکست descriptor و نبود امکان Apply دادهٔ کهنه حفظ شده‌اند؛ مسیرهای گشتن/اعمال با قرارداد preview-first هماهنگ شده‌اند.
- library82_host: شمارهٔ ماژول میزبان از ۳ به ۴ تغییر کرده تا API فقط‌خواندنی محل aerender/FFmpeg بار شود؛ کنترل revision متناظر به‌روز شده است.
- ui80_text_workspace_browser: تنها متغیر اختیاری مسیر گزارش اضافه شد تا شواهد UI83 بازنویسی نشوند؛ هیچ assertion تغییر نکرد.
- ui84_table_browser: selector سبک‌ها به workspace جدول محدود شد، چون متن هم پنل style دارد. برخوردِ نام data attribute به معنی تغییر شناسهٔ ثابت HTML نیست.
- ui84_panes_browser: سمت واقعی دستگیره تابع زبان است؛ تست انگلیسی از پایین راست درگ می‌کند. بعد از reload دیالوگ شروع پروژه را مثل کاربر می‌بندد. برای پایان پاسخ ResizeObserver منتظر دیده‌شدن واقعی ویرایشگر می‌ماند و همچنان حفظ ارتفاع، تمام‌صفحهٔ پر، هویت ورودی و بازیابی فهرست را بررسی می‌کند.

گیت UI84 به ۲۹ مقصد و ۸٬۳۵۲ ترکیب توسعه یافته؛ حداقل ۱۲px متن، ۳۲px هدف کلیک، عدم اسکرول افقی/برخورد/بریدگی، اقدام اصلی قابل مشاهده، حداکثر دو سطح ناوبری، نسبت محتوای حداقل ۵۰٪ و ثابت‌بودن سورس در حین آزمون حفظ شده‌اند. اجرای متوقف‌شده و خروجی پیش از اصلاح هدرها، پاس نهایی محسوب نمی‌شوند.

- ui69_interactions_browser: تعداد انتخاب‌گر از ۲۲ به ۲۹ افزایش یافته و مجموعهٔ دقیق ۲۲ صفحهٔ اصلی + هفت مقصد جدید مقایسه می‌شود. بررسی ستون‌ها از اولین form-grid قدیمی به خود pane-workspace واقعی منتقل شد؛ همان الزام دو ستون عریض/یک ستون فشرده و data-panel-band حفظ است. تست حالت باز، فونت، وزن خانه‌ها، هویت کنترل، کیبورد، focus، محتوای مؤلف و ResizeObserver همچنان اجرا می‌شود. اصلاح title padding تنها فضای واقعی برای overhang حروف فارسی در DPI کسری رزرو می‌کند؛ overflow پنهان نشده و tolerance آزمون تغییر نکرده است.
