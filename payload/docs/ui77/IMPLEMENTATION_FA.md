# ادغام UI77 در پنل افتر

مرجع ورودی: `Varna_UI77_Iconography_BlurControl.zip`، با SHA-256 برابر
`06d1de01c8b629db30db935d74e59c90f106c35a11f3ebe7c5bac000b73220ff`.
مبنای مقایسهٔ کد: `0c91a2e`.

فایل ورودی یک نمونهٔ HTML نمایشی با داده‌ها و فرمان‌های ساختگی بود. از آن برای جهت طراحی استفاده شد؛ اسکریپت‌های نمونه وارد اجرای پلاگین نشده‌اند. کنترل‌های واقعی، دادهٔ پروژه، موتور متن و فرمان‌های میزبانِ موجود حفظ شده‌اند.

## تغییرهای قابل مشاهده

- پوستهٔ مشترک برای ۲۲ صفحهٔ واقعی افتر: نوار ابزار، آیکون‌های هم‌خانواده، توضیح کوتاه، بخش‌های باز/بسته‌شونده و دکمهٔ اصلیِ ثابت.
- خانه با پنج کار مشخص و شروع سریع سه‌مرحله‌ای. جست‌وجوی قبلی با `Ctrl+K` و علاقه‌مندی‌های آن حفظ شده است.
- میانبرهای صفحه با سنجاق، جابه‌جایی با کشیدن یا دکمه‌های بالا/پایین، انتخاب سمت نوار، حالت جمع‌شده و بازنشانی. نام «میانبر» آن را از علاقه‌مندی‌های جست‌وجوی قبلی جدا می‌کند.
- تم‌های اصلی، اقیانوس، نعنا، اخگر، نوآر، رز و رنگ‌های دلخواه به تنظیم‌کنندهٔ قبلی متصل‌اند. تغییر روشنایی انتخاب رنگ را پاک نمی‌کند. زمینهٔ واقعیِ حالت روشن نیز با همان رنگ نمایش داده می‌شود.
- کنترل محوشدگی پس‌زمینهٔ رابط با ذخیرهٔ محلی. این مقدار وارد تنظیمات متن، افکت یا خروجی پروژه نمی‌شود.
- همان V حروفی قبلی: مسیر تصادفیِ هر کلیک، ۸۰۰ میلی‌ثانیه پخش‌شدن و پنج ثانیه بازگشت. حالت کاهش حرکت سیستم رعایت می‌شود.
- عنوان‌ها و کنترل‌ها روی پنل کوچک می‌شکنند؛ در ارتفاع کم نوارها مشترک می‌شوند. نوار سمت چپ/راست به‌جای رفتن به ستون دوم، فقط عمودی پیمایش می‌شود.
- فهرست کپشن، نمونه‌های بک‌گراند، انتخاب‌گرهای جست‌وجوشونده و کنترل‌های سریع کادر برای چیدمان تازه اصلاح شده‌اند.
- نصب بدون موتور، ۲۱ صفحهٔ قابل استفاده دارد؛ میانبر ساخت صدای وابسته به موتور نمایش داده نمی‌شود. زیرنویس و اصلاح آفلاین متن باقی می‌مانند. ارجاع دوره‌ایِ قدیمی به صفحهٔ حذف‌شده نیز محافظت شد.

## CSS و سازگاری

فایل تازه یک مالکِ موقتِ ارائه است؛ ادغام کامل CSS مرحلهٔ D در این تغییر ادعا نمی‌شود. تعداد فایل‌های CSS پیوندشده از ۳۵ به ۳۶، تعداد اعلان‌های `!important` از ۳۰۲۹ به ۳۲۲۸ رسیده است. علت استثناها در ابتدای فایل و کنار گروه‌ها آمده: قواعد مهم لایه‌های قبلی مانع نرمال‌سازی می‌شدند. برای برخورد با قواعد معمولیِ بدون لایه، قواعد معمولیِ دارای scope استفاده شده‌اند. هیچ فایل CSS قبلی بدون اثبات پوشش حذف نشده است.

۳۲۵ اندازهٔ لفظیِ کوچک‌تر از ۱۲ پیکسل در CSS قدیمی هنوز در سورس هستند؛ این عدد با اندازهٔ محاسبه‌شدهٔ رابط فرق دارد. آزمون مرورگر اندازهٔ واقعیِ متن و هدف کلیک را بررسی می‌کند. متنِ گرافیکِ پروژه از تنظیم اندازهٔ رابط جداست. نمونهٔ ثابتِ کوچک «VARNA MOTION» در کاتالوگ به نمونهٔ خواناتر حرکت تبدیل شد.

| ویژگی مورد استفاده | حداقل Chromium | مسیر اجرا |
|---|---:|---|
| CSS variables | ۴۹ | توکن‌های مشترک |
| Grid / فاصله در Flex | ۵۷ / ۸۴ | چیدمان پنل و کنترل‌ها |
| `min()` / `max()` / `clamp()` | ۷۹ | اندازه‌های محدود و خوانا |
| `:is()` / `:where()` | ۸۸ | scope و انتخاب‌گرهای مشترک |
| `aspect-ratio` / `overflow:clip` | ۸۸ / ۹۰ | قواعد پایلوت موجود |
| `@layer` | ۹۹ | مالکیت قواعد مهم؛ خط پایهٔ CSXS 12 |
| `backdrop-filter` | ۷۶ | جلوهٔ اختیاری؛ سطح خوانای معمولی باقی است |
| ResizeObserver / MutationObserver | ۶۴ / ۲۶ | اندازه‌گیری خود پنل و تغییر کنترل‌ها |
| Optional chaining / nullish coalescing | ۸۰ | همان خط پایهٔ JS قبلی |
| `replaceChildren()` | ۸۶ | ساخت ناوبری، بدون جایگزینی ورودی‌های اصلی |
| Dialog `showModal()` | ۳۷ | کاتالوگ قابل کنترل با صفحه‌کلید |

CSS تازه به container query، `:has()`، `color-mix()`، nesting یا واحدهای `dvh` متکی نیست. عرض از همان ResizeObserver و `data-size` می‌آید. پیاده‌سازی نوار قابل کشیدن از HTML Drag and Drop و دکمه‌های مستقلِ جابه‌جایی استفاده می‌کند.

اجرای بومی CEF 99 / CEP در این محیط انجام نشده است. تست محدودکردن قابلیت‌های جدید، مرورگر جدید را به موتور قدیمی تبدیل نمی‌کند؛ فقط مسیرهای جایگزین و عدم وابستگی به ویژگی‌های بعد از ۹۹ را بررسی می‌کند.

## حدود تأیید

ورودی‌های `premiere.html` و `resolve.html` و کد `host/` تغییر نکرده‌اند. این تحویل، ادغام رابط تازه در پنل After Effects است. اجرای واقعی CEP، نصب ویندوز، DPI ویندوز، فونت‌های نصب‌شده، رفتار جلوه‌های بومی و خروجی واقعی افتر نیاز به آزمون روی دستگاه دارند. تست مرورگر، اتصال میزبان را صریحاً mock می‌کند؛ نتیجهٔ رندر افتر یا موفقیت تولید صدا از آن استنتاج نمی‌شود.

چهار جفت اسلایدر دو دستگیره‌ایِ زمان/گرادیان عمداً روی یک مسیر قرار دارند. آزمون تنظیمات پیشرفته فقط همین چهار جفت نام‌برده را، با اثبات `type=range` و والد مشترک، به‌عنوان مسیر مشترک می‌پذیرد؛ هم‌پوشانی متن، دکمه یا کنترل دیگر مجاز نیست. تست‌های دائمیِ پیشین حذف یا ضعیف نشده‌اند.
