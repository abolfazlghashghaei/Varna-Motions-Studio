# مبنای رابط فشردهٔ UI85

منابع رسمی بررسی‌شده:

- [Fluent typography tokens](https://github.com/microsoft/fluentui/blob/master/packages/tokens/src/global/fonts.ts): اندازه‌های ۱۲ و ۱۴ پیکسل، وزن معمولی ۴۰۰ و متوسط ۵۰۰ در کنار وزن‌های قوی‌تر، نقش‌های جدا دارند. در وارنا متن عادی ۱۲ و عنوان بخش حدود ۱۲–۱۳ پیکسل است؛ تیتر اصلی نیز با مقیاس رابط تنظیم می‌شود؛ تنظیم اندازهٔ رابط همچنان مقیاس را تغییر می‌دهد.
- [Fluent spacing tokens](https://github.com/microsoft/fluentui/blob/master/packages/tokens/src/global/spacings.ts): فاصله‌های ۰، ۲، ۴ و ۶ پیکسل هم بخشی از مقیاس رسمی‌اند. گروه مرتبط به فاصلهٔ کوچک نیاز دارد؛ padding بزرگ برای هر لایه لازم نیست.
- [Spectrum Field Label](https://github.com/adobe/spectrum-css/blob/main/components/fieldlabel/index.css): وزن regular، padding افقی صفر و margin صفر برای برچسب‌ها تعریف شده است. همهٔ برچسب‌ها عنوان بولد نیستند.
- [Spectrum Divider](https://github.com/adobe/spectrum-css/blob/main/components/divider/index.css): جداکننده سطحی باریک و ساده است. مرز ناحیه‌ها در وارنا با خط جایگزین قاب چندلایه و سایهٔ بیرونی می‌شود.
- [WCAG 2.2 Target Size Minimum](https://github.com/w3c/wcag/blob/main/understanding/22/target-size-minimum.html): حداقل عمومی ۲۴×۲۴ CSS px است. کف قوی‌تر قبلی وارنا، ۳۲px، حفظ شده است؛ کوچک‌شدن ظاهر از کاهش padding، وزن متن و لایه‌بندی حاصل می‌شود.

دسترسی مستقیم به سایت‌های طراحی Spectrum/Fluent از proxy این محیط 403 بود؛ منابع کد رسمی همان سازندگان واقعاً دریافت و خوانده شدند. کد کتابخانه‌ای کپی یا وابستگی تازه نصب نشد.

## تصمیم اجرا

- وزن برچسب‌ها ۴۰۰، کنترل و عنوان بخش ۵۰۰؛ متن زیر ۱۲px نمی‌رود.
- فاصلهٔ ناحیه‌ها حدود ۲px، فیلدها ۴px و padding کارت داخل ناحیه صفر؛ خود بدنه حدود ۴px دارد.
- line-height برابر ۱٫۵ با فونت فعلی فارسی. نمونهٔ ۱٫۳۵ به برخورد جزئی دنبالهٔ حروف و راهنما منجر شد و با همان اوراکل برخورد رد شد؛ فشردگی نباید به هم‌افتادگی متن بدهد.
- یک اسکرول ستونی برای تنظیمات پیش‌فرض؛ با تغییر اندازهٔ دستی یا تمام‌صفحه، اسکرول همان ناحیه فعال می‌شود.
- ارتفاع‌های UI84 در کلید قبلی دست‌نخورده می‌مانند. UI85 فضای نام تازه برای اندازهٔ پنل دارد؛ فقط تغییر اندازهٔ دستی ذخیره می‌شود، نه هر تغییر اندازهٔ خودکار محتوا.
- رنگ‌های سفارشی، روشن/تیره، RTL، منطق ورودی‌های عددی و دادهٔ خروجی پروژه حفظ‌اند. هیچ فایل CSS جدیدی به زنجیره اضافه نمی‌شود؛ مالک فعلی قواعد اصلاح می‌شود.

دکمهٔ پیش‌نمایش جدول همان عنصر و handler قبلی است و اکنون کنار عنوان پیش‌نمایش می‌ماند. کنترل‌های پیشرفتهٔ قبلی حذف نشده‌اند. !importantهای تازه فقط در مالک A68 برای غلبه بر وزن، اندازهٔ خط و padding ثابت legacy لازم‌اند و دلیل در همان بلوک CSS ثبت شده است.
