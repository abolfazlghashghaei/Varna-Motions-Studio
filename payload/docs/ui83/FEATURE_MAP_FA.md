# نقشهٔ قابلیت‌ها و حدود بررسی UI83

چیدمان و دسترس‌پذیری تمام ۲۲ صفحه در مرورگر بررسی می‌شود. این بررسی، تضمین اجرای تمام خروجی‌های میزبان یا سرویس AI نیست. هیچ قابلیت سالمی بر اساس شکست fixture قدیمی حذف نشده است.

## بخش‌های مستقل ابزارها

- عنوان بومی، گرادیان متحرک، هایلایت بومی: سه فرم مستقل با همان فرمان‌های میزبان قبلی.
- ۲۵ عنوان، ۱۰۰ عنوان اجتماعی، ۱۰۰ معرفی، اجزای اینستاگرام، زمینه‌های تکنولوژی، Neon، Light Leaks و Paper Burn: انتخاب کامپوزیشن → متن و کنترل‌های همان طرح → افزودن کپی مستقل. Lower thirds تصاویر واقعی دارد.
- Holographic Foil: مقصد و محدوده → خواندن schema واقعی → کنترل‌های اصلی → اعمال. فایل AEX باید در افتر شناسایی شده باشد.
- Highlighter و Amanow: ابزار اصلی فقط با اقدام کاربر باز می‌شود. نصب/تکمیل Amanow کنار خودش است.
- Orb، WriteTyper، Glassary، Cuttana، Smart Captions: هر کدام ورودی و وضعیت خودشان را دارند. فایل ناموجود به «نیازمند راه‌اندازی» می‌رود.
- DJ Subtitle: زیر بخش اختیاری Neon. اگر رابط فقط پنجرهٔ خارجی بدهد یا کنترل قابل اتصال نداشته باشد، قاب خالی نشان داده نمی‌شود؛ طرح Neon و متن ویرایش‌شده باقی می‌ماند.

## موارد پنهان‌شده و دلیل

فرم و تب‌های تکراری کتابخانه، انتخاب‌گر تکراری نوع کار بومی، دکمهٔ تکراری ساخت داخل فرم در کنار اقدام ثابت، جزئیات خام قلم و کنترل readonly از مسیر اصلی کنار رفتند. کنترل واقعی، ID و handler حذف نشده‌اند. مقدار قلم خام در پیشرفته باقی است؛ کنترل فقط‌خواندنی به‌عنوان فیلد قابل تغییر نشان داده نمی‌شود. ابزار نصب‌نشده و فرمان ناموجود، کنترل عملیاتی ساختگی ندارد؛ مسیر بررسی و راه‌اندازی دارد.

هیچ کتابخانهٔ اصلی، تنظیم پروژه، مدل، فونت یا منطق فعال‌سازی فروشنده حذف یا دستکاری نشده است.
