# UI82 — reachable preview and complete supplied packs

UI-only preview change: preserve livePreviewGlobal itself, its ID, state and
existing app.js On/Off handlers. Its label lives in the non-scrolling action bar,
with a power icon, checked color, keyboard focus, short-panel tooltip and a wide
panel state label. Both the pilot popover owner and studio37's old resize owner
cede this input to flow77 on UI77 only. Other hosts keep their current layout.

The nineteen supplied RAR volumes are read by libarchive, without running any
archive content. The assembled outer archive contains the five exact missing
originals. The full local library replaces the earlier Amanow 74-file bundle
with its complete 3948-file original; it adds Neon AEP/DJ JSX, Light Leaks AEP
plus all Footage, Paper Burn AEP plus all Footage, and the x64 Foil AEX.
There are 11 pack destinations: ATools and Amanow are the same bundle, not two.

Fixed catalog paths feed the existing import/clone/inspector pipeline. Missing
footage is relinked only by a unique basename inside the chosen pack's Footage
folder. Already available footage and earlier project items are not modified.
Transitions keep original duration and size; Light Leaks supports centering at
the current cut and Collapse Transformations, following its supplied guide.
Unknown/dynamic comp-name expressions retain the existing validator limitations.
DJ's opaque original script has the existing explicit ScriptUI bridge; no
compiled code is decoded, patched or started by inventory.

Foil registers with the existing native-effect inspector/state pipeline, using
its real effect name and actual host-provided property schema. Max installer
adds its exact native source/target pair to the existing verified copy/rollback
plan only when the bundled library contains it. A different existing binary is
preserved as a conflicting component; no license logic is changed.

Amanow installation can complete a prior Varna-managed bundle only if every
owned file is unchanged and there are no unknown extra files. New files are
staged and checked, previous bundle is renamed to a retained backup, activation
is atomic and a failed activation restores the old bundle. Unmanaged/modified
installations are preserved. Vendor runtime behavior and native Windows/Adobe
acceptance remain untested here.

Three instruction videos are excluded from the install payload, never runtime
assets. Their original bytes remain in the local extraction. PDFs and all media
needed by actual effects/templates remain in the library. Original file hashes
and volume integrity are recorded separately from public source code.
