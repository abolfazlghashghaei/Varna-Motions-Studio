# نصب و نگهداری — Installer60

پوشهٔ تحویل فقط پنج فایل اجرایی دارد: سه نصب‌کنندهٔ AE، Premiere و Resolve، یک حذف‌کنندهٔ موتور و یک تعمیرکننده. فایل‌های داخلی در پوشهٔ payload قرار می‌گیرند؛ آن‌ها را جابه‌جا نکنید.

داخل هر نصب‌کننده، ۱ برای همراه موتور و ۲ برای بدون موتور است. نصب همراه موتور فعلاً NVIDIA می‌خواهد. انتخاب بدون موتور، ماژول‌های اختصاصی ساخت موسیقی/صدای ComfyUI را از فایل‌های نصب‌شده کنار می‌گذارد؛ زیرنویس، صداهای آماده و اصلاح آفلاین واژه‌ها مستقل باقی می‌مانند. کتابخانه‌های مشترک که امکانات دیگر هم به آن‌ها وابسته‌اند حذف نمی‌شوند.

ابتدا موجودی C تهیه و گزارش در TEMP ذخیره می‌شود. پوشه‌های دارای نام Varna/GHAF/QAF/قاف/وارنا و ساختار واقعی ComfyUI شناسایی می‌شوند. پوشه‌های غیرقابل‌خواندن رد می‌شوند و junction/symlink دنبال نمی‌شود؛ تضمین دسترسی به تمام حساب‌های کاربران بدون اجرای Administrator وجود ندارد.

حذف‌کننده مسیرها را نشان می‌دهد. تنها با تایپ DELETE ENGINES همان پوشه‌ها و کش اختصاصی Downloads59 (اگر در فهرست باشد)، شامل مدل‌های داخلشان، برای همیشه حذف می‌شوند. از مدل‌های موردنیاز نسخهٔ پشتیبان بگیرید. پوشهٔ مادر Varna/GHAF، پروژه‌ها، پلاگین‌ها و ComfyUIهای بدون نشان برند خودکار حذف نمی‌شوند. موتور در حال اجرا باید ابتدا بسته شود.

تعمیرکننده نام میزبان و حالت موتور را دوباره می‌پرسد. موتور سالم و فایل دانلود تأییدشده استفادهٔ مجدد می‌شوند. فایل ناقص ادامه دانلود داده می‌شود. خرابی موتور به‌جای پاک‌کردن مدل‌ها با staging مستقل تعمیر می‌شود.

گزارش ارسالی دانلود موفق و شکست health check را نشان می‌دهد، اما علت Python در آن موجود نیست. نسخهٔ جدید exit code و stdout/stderr را مستقیم ثبت می‌کند؛ علت قطعی شکست قبلی بدون فایل diagnostic مشخص نیست.

این ابزار در محیط ابری روی فایل‌های آزمایشی آزموده می‌شود؛ اسکن و حذف روی C واقعی و نصب Windows/Adobe در این محیط اجرا نشده‌اند. حذف‌کننده روی کامپیوتر شما فقط پس از مشاهدهٔ فهرست و تأیید خودتان عمل می‌کند.

اصلاح ۶۰٫۲: لینک پوشه یا فایل داخل موتور فقط unlink می‌شود و مقصد آن حفظ می‌شود. آزمون واقعی symlink، حفظ بایت‌های مدل بیرونی، لینک شکسته و جلوگیری از حذف ریشهٔ لینک‌شده در لینوکس گذشت. آزمون junction و حذف روی Windows واقعی هنوز اجرا نشده است.

اصلاح ۶۰٫۳: فایل کمکی VarnaDownload.psm1 در payload قرار دارد. فایل‌های عادی Read-only مانند indexهای Git پیش از حذف از این حالت خارج می‌شوند؛ لینک‌ها و مقصد مدل‌های خارجی دستکاری نمی‌شوند. در خطای واقعی مجوز یا فایل قفل‌شده، حذف متوقف و راهنمای اجرای Administrator/بستن برنامه نمایش داده می‌شود؛ ACL و مالکیت خودکار تغییر نمی‌کنند. bundledExtractor=False در حذف‌کنندهٔ مستقل خطا نیست و اکنون در نمایش اصلی آن نشان داده نمی‌شود.
