# گزارش تحویل Varna Motion Studio 4.3 R14 RC1

مبنای این بسته، فایل `Varna_Motion_Studio_4.3_PRO_STABLE_R13(1).zip` و فهرست ایرادهای پیوست همین گفتگو است. این خروجی با نسخه‌های ساخته‌شده در گفتگوهای دیگر ادغام نشده است.

**وضعیت: نسخهٔ اصلاح‌شدهٔ آمادهٔ نصب و آزمون، با تأیید اجرای واقعیِ باقی‌مانده.**

**Requires real After Effects runtime verification.**

برچسب Stable استفاده نشده است. این محیط Linux است و Adobe After Effects 2026، CEP ویندوز، GPU و مدل‌های GGUF کاربر در آن در دسترس نیستند.

## نتیجهٔ آزمون‌ها

۱۱ مجموعه تست انتخاب‌شده برای قرارداد R14 با موفقیت اجرا شدند. خروجی کامل در `TEST_RESULTS_R14.txt` است.

| سطح آزمون | نتیجه و دامنه |
|---|---|
| Syntax و قرارداد کد | اسکریپت‌های پنل و Host قابل Parse؛ منابع UI موجود؛ ID تکراری و فراخوانی Host بدون تعریف پیدا نشد |
| منطق کپشن | انتخاب، ادغام/تفکیک، زمان متن، Undo/Redo، کشیده و متن فارسی/انگلیسی بررسی شد |
| R14 رفتاری | ۱۶ سناریو برای زمان، حافظه، مدل، صدا، جدول، تراکنش خروجی و CEP؛ Host افتر در این آزمون مدل‌سازی شده است |
| SFX | ۱۲ Assertion برای جداسازی Ambient، محدودیت صدا و Beat و حذف کپشن‌ها |
| صوت واقعی | FFmpeg روی WAV آزمایشی واقعی؛ Loudness و True Peak منبع در بازهٔ مشخص اندازه‌گیری شد |
| HTTP محلی | درخواست واقعی روی 127.0.0.1، UTF-8 و «ژ»، کلید دسترسی، نام مدل و صف درخواست‌ها؛ خود فرآیند مدل شبیه‌سازی شده است |
| UI | رفتار منطق رابط با DOM شبیه‌سازی‌شده؛ این تست تأیید بصری مرورگر/CEP نیست |
| After Effects 2026 | اجرا نشده؛ نیازمند تست واقعی |
| نصب Windows | کد و مسیر نصب بازبینی شده؛ نصب روی Windows اجرا نشده |
| نمایش 250×250 و متریال نهایی | بررسی بصری در این محیط انجام نشده؛ دریافت Chromium معتبر موفق نبود |

آزمون‌های تاریخی وابسته به نام R8/R10/R11/R12/R13، نام‌های قدیمی Marker، Fuzzy خودکار یا موتور قدیمی حفظ شده‌اند و پاس‌شده حساب نشده‌اند. دلیل دقیق در `tests/README.md` آمده است. تست‌های Mock برای ادعای رفع قطعی رفتار افتر کافی نیستند.

## Assetهای ارسالی

- همهٔ ۱۷۴۷ فایل Asset با SHA-256 با ZIP مبنا مقایسه شدند و تغییر نکرده‌اند.
- ۸۱۸ فایل mhcitem با پیش‌نمایش متناظر `mhpreview.webm` در فهرست ثبت شده‌اند. نتیجهٔ بررسی Container/Codec و اندازه/مدت ویدیوها در `ASSET_AUDIT.json` است.
- چهار AEGraphic و فایل‌های Engine اصلی نگه‌داری شده‌اند؛ این فایل‌ها در محیط حاضر اجرا یا نصب نشده‌اند.
- ۶۷ فایل WAV شامل ۶۶ فایل ارسالی و صدای تایپ داخلی نگه‌داری شده‌اند.
- ۴۳ موشن Native، پیاده‌سازی مستقل موجود در پنل هستند؛ معادل اجرای همهٔ ۸۱۸ فایل اختصاصی نیستند.
- طبقه‌بندی محتوای تمام پیش‌نمایش‌ها به Text/Non-text انجام نشده است. دادهٔ اختصاصی mhcitem حدس زده نشده و وضعیت ناشناخته در فهرست حفظ شده است. `ASSET_PREVIEWS.html` امکان بازبینی پیش‌نمایش‌ها را می‌دهد.

## محدودیت‌ها و تأییدهای باقی‌مانده

1. بررسی واقعی روی AE 2026: اتصال CEP، ساخت و رندر کپشن فارسی/انگلیسی، IN/OUT/BOTH، تایپ و صدا، Preview روشن/خاموش و Undo.
2. بررسی بصری شیشه روی تصویر روشن/تیره و ویدیو؛ کنترل‌های Native افکت و Expressionها باید روی همان نسخهٔ افتر تأیید شوند. این متریال یک تقریب Native از شیشه است.
3. بررسی جدول‌های 3×3 و 5×4، جهت RTL/LTR، کشیدن مرزها، مرج/Unmerge، زمان صفر، مارکر متن و گوشه‌های بیرونی در افتر.
4. اجرای واقعی هر مدل GGUF و projector سازگار با Runtime و GPU کاربر؛ آزمون فعلی کیفیت خروجی مدل، دقت Vision یا ظرفیت VRAM را تأیید نمی‌کند.
5. تراز صدا بر مبنای منابع است. Effects صوتی افتر، تغییر زمان پیچیده، میکس نهایی و Loudness/True Peak خروجی نهایی باید پس از رندر کنترل شوند. لایهٔ Time Remap یا معکوس برای تحلیل منبع نیاز به رندر صوتی دارد.
6. حافظهٔ اصلاح متن عمومی/پروژه دارد؛ یادگیری SFX در این نسخه عمومی است و تفکیک مستقل پروژه‌ای برای آن اضافه نشده است.
7. سازگاری کامل و اجرای مستقیم بسته‌های اختصاصی Animation Composer تکمیل نشده است؛ این بسته ادعای ادغام مستقیم آن‌ها را ندارد.

## آزمون کوتاه پس از نصب

- پروژهٔ آزمایشی ۱۰ ثانیه‌ای با یک ویدیو، دیالوگ، موزیک و چند Keyframe بسازید؛ پنل را در اندازهٔ کوچک و بزرگ باز کنید.
- از تنظیمات پنل تست موقت Host را اجرا کنید؛ وجود خطا را با گزارش ذخیره‌شده بررسی کنید.
- یک کپشن فارسی و یکی انگلیسی با متن، پس‌زمینه و صدا بسازید. Preview و خروجی را در زمان مشابه مقایسه کنید.
- یک کلمهٔ وسط جمله را تقسیم/اصلاح کنید؛ شروع کلمه‌های بعدی باید ثابت بماند. Undo/Redo را بررسی کنید.
- جدول را از ثانیهٔ ۰ تا ۸ بسازید، متن یک خانه را ۳ تا ۶ تنظیم کنید، Preview را پاک کنید و وجود لایهٔ اضافه را بررسی کنید.
- SFX را Analyze و Preview کنید؛ Cue یک رویداد در ثانیهٔ ۴ باید در همان زمان قرار بگیرد. Ambient برای کات کوچک نباید انتخاب شود.
- Audio Balance را دو بار بزنید؛ تغییر تجمعی نباید رخ دهد. سپس یکی از کی‌فریم‌ها یا Ease آن را دستی تغییر دهید؛ اجرای بعدی باید لایه را حفظ کند.
