# Varna Motion Studio 4.5 RC25

این نسخه بر پایهٔ بستهٔ کامل RC24 ساخته شده است. فایل‌های اصلی هفت پک و نصب‌کنندهٔ BAT تغییر نکرده‌اند. RC25 یک بستهٔ کامل است و به نصب جداگانهٔ RC24 نیاز ندارد.

## تغییرهای این نسخه

| بخش | رفتار RC25 |
| --- | --- |
| Orb Reactor | مسیر CSS/JS از پوشهٔ `client` محاسبه می‌شود؛ ریشهٔ افزونه برای shader و فایل‌های اصلی مستقل می‌ماند. خطاهای بارگذاری فایل و Promise در پنل نمایش داده می‌شوند. |
| Glassary | مسیر اصلی روی Shape خودکار و دنبال‌کنندهٔ کپشن اجرا می‌شود. Shape دستی یک اقدام اختیاری جداگانه است. |
| Cosmic بک‌گراند | انتخاب مستقل یا ترکیب با شیشهٔ وارنا؛ ترکیب دارای لایهٔ رنگ جدا با شدت قابل تنظیم، اندازه/فاصله/گوشهٔ مشترک و سطح شیشه‌ای روی آن است. |
| Cosmic حروف | تنظیمات مستقل از Cosmic بک‌گراند؛ امکان استفادهٔ تنها یا همراه AE Glass حروف. |
| AE Glass حروف | ده کنترل نور و اپتیک مستقل از بک‌گراند؛ اپاسیتی رنگ اصلی حروف همچنان قابل تنظیم است. |
| نوشتار | انتخاب بین تایپ وارنا و WriteTyper؛ کنترل‌های هر مسیر جدا نمایش داده می‌شوند. |
| تایپ وارنا | روشن/خاموش مستقل؛ رشد کادر روشن/خاموش مستقل. خاموش‌کردن رشد، بک‌گراند را حذف نمی‌کند و کادر با اندازهٔ نهایی ثابت می‌ماند. رشد دارای هموارسازی کوتاه هندسی است. |
| به‌روزرسانی تایپ | اعمال روی لایه‌های خروجی موجود، پاک‌کردن Expression و کلیک‌های متعلق به تایپ قبلی هنگام خاموش‌کردن آن. |
| برند | نام، حوزه و توضیح برند؛ ذخیرهٔ ظاهر فعلی متن، بک‌گراند، افکت‌ها، موشن و چیدمان اختیاری. انتخاب و اعمال یکجا بعد از تولید زیرنویس؛ یک مرحله Undo در پنل. |
| تنظیمات افکت | دسته‌بندی رنگ/نور، ماتی/بافت و عمق/شیشه؛ تغییر دسته مقدار ویرایش‌شده را از بین نمی‌برد. «اعمال» مقدار ویرایش‌شده را ذخیره می‌کند. |
| Cuttana | نام و زمینهٔ کنترل‌ها از پنل اصلی خوانده می‌شود؛ علاوه بر سبک‌های سریع، می‌توان فرمان واقعی مشخص را از فهرست خواند و انتخاب کرد. فرمان بی‌نام به‌صورت حدسی اجرا نمی‌شود. |
| فضای پنل | کارت‌های ظاهر متن عرض پنل را می‌گیرند؛ در عرض کم یک ستون، در عرض بزرگ دو ستون و کارت تنظیمات اصلی متن تمام‌عرض است. |

## استفاده

۱. After Effects را ببند. بسته را کامل استخراج کن و `INSTALL_WINDOWS.bat` را اجرا کن. برای نصب پک‌های همراه، سطح Max را انتخاب کن. مسیر تشخیص موتور مشترک و قواعد حفاظت از نصب قبلی همان RC24 است.

۲. در بک‌گراند، Cosmic یا Glassary را از هدر انتخاب کن. «روش استفاده» را مستقل یا ترکیبی قرار بده. تنظیمات اصلی را بخوان، تغییر بده و «اعمال» را بزن. برای Glassary خودکار نیازی به دادن Shape نیست؛ در حالت دستی Shape خودت را در AE انتخاب کن.

۳. برای شیشهٔ متن، در «رنگ و شیشهٔ حروف» جنس حروف را AE Glass یا Cosmic + شیشه انتخاب کن. تنظیمات حروف در همین بخش است و به کادر دست نمی‌زند.

۴. در بخش موشن ← تایپ و کادر، روش نوشتار را انتخاب کن. تایپ وارنا و رشد کادر کلیدهای جدا دارند. «اعمال تایپ وارنا» تنظیمات و لایه‌های خروجی مربوط را به‌روز می‌کند. برای رشد از حرف اول، هر دو کلید را روشن کن. برای نوشتن متن در کادر ثابت، فقط رشد را خاموش کن.

۵. ظاهر یک کپشن را تنظیم کن؛ از خانه به «برند بساز و اعمال کن» برو. اجزایی را که می‌خواهی ذخیره شوند انتخاب کن و برند را ذخیره کن. بعد از تولید زیرنویس جدید، برند را انتخاب کن و روی همه یا کپشن انتخابی اعمال کن. چیدمان خطوط سراسری است و برای برند دارای چیدمان، محدوده باید همه باشد.

## محل پک‌ها

| پک | محل دسترسی |
| --- | --- |
| Orb Reactor | خانه ← گوی واکنشی؛ رابط اصلی در وارنا |
| Glassary | بک‌گراند ← انتخاب مدل Glassary؛ گزینهٔ Shape دستی جدا |
| Cosmic | بک‌گراند ← مدل Cosmic؛ متن ← جنس حروف Cosmic |
| Smart Captions Engine | موشن ← ابزارهای نوشتار ← قالب و تنظیمات Smart؛ فایل AEP اصلی حفظ شده |
| WriteTyper | موشن ← تایپ و کادر ← روش WriteTyper؛ تنظیمات کامل نیز در دسترس |
| CuttanaNir3 | موشن ← ابزارهای نوشتار ← Cuttana؛ سبک سریع و فرمان اصلی قابل انتخاب |
| Railcut | خانه یا گردش کار تدوین ← تایم‌لاین؛ پنل اصلی برای docking در AE |

## حدود تأیید

آزمون‌ها کد جاوااسکریپت، مدل حالت، DOM نمونه، Expression تولیدشده و منطق Host با نمونهٔ API را بررسی می‌کنند. Chromium و After Effects ویندوز در محیط ساخت موجود نیستند؛ خروجی تصویری Orb/WebGL، اجرای واقعی AEX/JSXBIN، ظاهر شیشه‌ها و نصب ویندوز در این محیط آزمایش نشده‌اند. اصلاح مسیر Orb در آزمون منابع تأیید شده است؛ این به‌معنی تأیید اجرای GPU یا وضعیت فعال‌سازی آن روی سیستم کاربر نیست.

تمام فایل‌های اصلی پک‌ها، امضاها و مسیرهای فعال‌سازی حفظ شده‌اند. قابلیت‌های اصلی هر ابزار به نصب و شرایط اجرای خود آن ابزار وابسته‌اند. اگر فرمان سریع Cuttana از نام کنترل‌ها قابل تشخیص نباشد، فهرست فرمان‌های اصلی یا تنظیمات کامل را استفاده کن؛ خطا به‌عنوان اجرای موفق گزارش نمی‌شود.

برند صرفاً تنظیمات خلاقه را ذخیره می‌کند و موتور، مسیر مدل، فایل رسانه یا زمان گفتار را جابه‌جا نمی‌کند. برندها در تنظیمات محلی و دادهٔ پروژه ذخیره می‌شوند و در پروژه‌های بعدی قابل انتخاب‌اند.
