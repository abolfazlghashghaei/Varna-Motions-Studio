# Varna Motion Studio 4.5 RC47

این بسته جمع‌بندی بررسی و اصلاح قالب‌ها، پیش‌نمایش، ذخیرهٔ پروژه، وضعیت کپشن‌ها، پس‌زمینه و موتور موسیقی است. مسیر پایهٔ بارگذاری RC43 و ساخت کپشن‌به‌کپشن حفظ شده است.

## نصب

افتر را کامل ببند. ZIP را در پوشه‌ای تازه استخراج و INSTALL_WINDOWS.bat را اجرا کن. بالای پنل باید **RC47** دیده شود.

## قالب و موگرت

کپشن را انتخاب کن، وارد «قالب‌ها» شو و قالب را بارگذاری کن. کنترل‌های ساختاری و غیرقابل‌ویرایش افتر دیگر به‌عنوان تنظیم قابل‌ویرایش نمایش داده نمی‌شوند. «پیش‌نمایش در افتر» نتیجهٔ متن فعلی را می‌سازد. برای خروجیِ شامل تمام اجزای قالب از «اعمال و ساخت خروجی کامل» استفاده کن.

وابستگی‌های خارجیِ هم‌نام، فقط از مجموعهٔ همان قالب خوانده می‌شوند. حذف آخرین خروجی، نسخه‌های موقت متعلق به آن را هم پاک می‌کند.

رنگ‌های اصلی به‌صورت پیش‌فرض حفظ می‌شوند. برای جایگزینی رنگ تأکید، نقش رنگ را صریحاً انتخاب کن. تنظیمات قدیمیِ شامل گروه‌های ساختاری قابل‌شناسایی، هنگام ساخت نادیده گرفته می‌شوند؛ مسیر واقعاً تغییرکرده با پیام مشخص متوقف می‌شود.

## اصلاح‌های دیگر

- پاسخ نامعتبر یا null از افتر دیگر صف فرمان‌ها را معطل نمی‌گذارد. اگر نهایی‌سازی انجام شده ولی پاسخ آسیب دیده باشد، رسید همان جلسه خوانده می‌شود تا خروجی دوباره ساخته نشود.
- پیش‌نمایش زنده و فریمی از مقصد مشخص استفاده می‌کنند؛ فعال‌بودن پوشهٔ پروژه به‌جای کامپوزیشن مانع آن نمی‌شود. لایه‌ها و وابستگی‌های موقتِ متعلق به پیش‌نمایش پاک می‌شوند.
- دادهٔ پروژه بدون وابستگی به Array.some خوانده می‌شود؛ قطعه‌های مفقود یا تکراری داده شناسایی می‌شوند.
- تایپوگرافی خاموش، اندازه و چیدمان کپشن عادی را تغییر نمی‌دهد. اگر تغییر متن تقسیم‌بندی را نامعتبر کند، خروجی بازسازی می‌شود و پیام بررسی چیدمان نمایش داده می‌شود؛ طرح ذخیره‌شده محفوظ می‌ماند.
- Undo/Redo ورود زیرنویس، مبنای «بازگشت به اصل» را هم بازیابی می‌کند.
- خاموش‌کردن صریح پس‌زمینهٔ متن انتخابی، اجزای متعلق به آن را حذف می‌کند. اعمال مکرر تایپ یا نهایی‌سازی پس‌زمینه، لنگر و اندازه‌گیر پنهان تکراری نمی‌سازد.
- تنظیمات عددیِ موشن خاموش غیرفعال می‌شوند و مقادیرشان برای روشن‌کردن دوباره حفظ می‌شود.
- علت خطای راه‌اندازی موتور موسیقی بهتر گزارش می‌شود؛ خطای نهایی ذخیرهٔ فایل صوتی به‌درستی پایان می‌یابد و فایل ناقص پاک می‌شود.

## وضعیت تأیید
