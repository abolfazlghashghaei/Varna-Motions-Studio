# Studio54 acceptance and compatibility

Base: Studio53 `492a2a5`. The user-approved scope is an AE editing workspace, including its detached companion, and production tools in Premiere/Resolve. The two other hosts do not receive the NLE controller. A matching control in the UI is not evidence that an AE-native binary effect has become portable.

| Area | Studio54 implementation | Remaining boundary |
|---|---|---|
| Exit / reopen | Root obeys hidden; pauses source/audio/shuttle, releases main-panel inert state, restores original controls and overlays | Native CEP fullscreen transitions still need Adobe testing |
| Production in editor | Dynamic registry moves actual original pages into inspector; includes text/review/translation/typography/motion/background/table/audio/brand/curves/assistant/settings and future pages | AE-only provider calls require actual AE; standalone cannot execute AE binary effects |
| Caption state | Approved panel changes retain stable timeline identity; editor edits, deletion and Undo return to panel; caption order mapped by time | A changed imported caption may rebuild its tokenization; automatic approval is never inferred |
| Dialogs / shortcuts | Original quick style/split/merge/motion-scope dialogs move with controls, render above editor, and return on exit; production typing and Alt shortcuts bypass NLE hotkeys | Existing localization dictionary still has some untranslated diagnostic/model text |
| Main panel brand New | Resets creative settings and per-caption overrides with Undo; keeps content, saved brands and system paths | New brand is not a command to delete media or create a new timeline |
| Full host UI | Premiere/Resolve generated from canonical index; same original production fields/events rather than a reduced title editor | Unsupported host commands return explicit errors; not every vendor pack has a host-neutral provider |
| Premiere provider | Real sequence dimensions/FPS, selected media source trims, markers/time, imports, confirmed exact video/audio placement, owned-output replacement | Native API verified against SDK model; actual Premiere activation/rendering unrun; needs a free destination track |
| Resolve startup | Lua connector starts verified own Electron runtime before UIManager checks; real startup errors/logs, heartbeat/session filesystem RPC | Windows x64; native scripting/UIManager depends on Resolve edition/configuration; actual Resolve activation unrun |
| Resolve provider | Timeline/markers/source/time, brand assets, frame-exact video/audio import, overlap isolation, owned-only graphic removal | Controlled Lua SDK model; no claim of universal Resolve Free support |
| Shared graphics | Gradient/stroke/glow text, background plates, entry/word/kinetic styles, shapes and custom curves use same preview/export pipeline | Canvas optics differ from native effects; unsupported FFX/composition/vendor effects fail before render |
| Full table | Original designer and preview payload; unified/independent surfaces, continuous merge-aware dividers, cell timing, RTL, alignment/padding/colors/entries | Shared glass approximates native optics; no underlying host-footage sampling in exported alpha |
| Native delivery | Persistent alpha MOV outside temporary frames; actual insertion confirmation; retain completed render if native placement outcome is uncertain | Text is raster graphics on video track; MOGRT/Text+ remain separate supported paths |
| Safe areas / legacy markers | Original safe-area designer and text-fit rules retained; sound-cue markers write/read through each compatible native provider | Native safe-guide layers and legacy marker-only text output still use the original AE provider; unsupported shared-host actions report an error rather than success |
| Media compatibility | Unsupported browser video can transcode via FFmpeg; original paths retained; compatible preview persisted/recovered alongside originals and detached handoff | SDR/8-bit browser pipeline; not managed HDR/native GPU decoder parity; FFmpeg required |
| Assistant | Local model proposes bounded validated JSON commands; explicit review before Apply; atomic changes and Undo; real native AE script target remains selectable | Not unrestricted scripting in non-AE hosts; GPU inference/output quality unrun |
| Curves | Custom Bezier on animated clip/shape properties; independent shape Width/Height keeps roundness; native AE adapter bakes compatible keys | No universal host-specific property/effect graph |
| Installation | Exact source hashes, staged activation/backup/restore, runtime archive/file verification, full runtime repair, Lua without BOM; existing AE LFS restoration intact | PowerShell filesystem test on Linux is not Windows registry/application activation |

Studio53's actual media/edit/export/OTIO/job capabilities remain described in `STUDIO53_SECTIONS.md`. The Studio54 rows above supersede its reduced shared UI, Python/Node-PATH Resolve launch, brand-import and original-table-control limitations. Full multicam, tracking, optical flow, temporal denoise, scopes, managed HDR, native third-party effect portability and complete NLE parity remain unimplemented; interface resemblance does not imply those features.
