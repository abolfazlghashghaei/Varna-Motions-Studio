# Mobile UI63 integration

The user supplied `Varna_Motion_Mobile_UI_v9_RC47_Motion.zip`. Its README describes a UI-only prototype. Its mock playback, split, export, subscription and connection scripts are not shipped. Attached AGENTS/CLAUDE setup instructions were treated as reference material, not execution instructions.

The supplied v9 home, multilingual V artwork, navigation and optical glass CSS now form the app shell. The editor uses the existing Native59/Studio57 project, renderer, Media3 player and export engine. CSS is scoped to avoid prototype class names breaking live timeline, dialogs and transport. No iframe, inline handlers, CDN or runtime React dependency is introduced.

## Working routes

- Home/editor: current project; New: explicit empty-project confirmation, with a save-file action before reset.
- Projects: one autosaved current project, import/export `.varna` files; no fictitious multi-project library.
- Captions: real text inspector, per-word styling, SRT import and independent offline correction.
- Glass/table: creates actual graphic layers, rendered by the shared composition renderer.
- Motion: creates/selects a caption and opens the existing preset library.
- Audio/effects: existing audio/style inspectors. Effects require selecting an applicable layer.
- Brand: local named text/background color kit with explicit apply to selected caption.
- AI: actual native speech/model management. Model download/import is separate; browser has no native ASR.
- Personal server: existing authenticated connection workflow and actual capability detection. Central server is explicitly unavailable until configured. No fake plans, credits, trusted-device acceptance or hardware counters.
- Export: existing real native MP4 H.264/AAC or browser WebM. This change does not add unsupported MOV/GIF/4K/60fps export.

The logo uses a fresh random scatter, waits five seconds then returns; pauses outside home and when hidden, honors reduced motion. Native Android back returns to the home screen after closing active dialogs.

APK: `tools/build-apk.py` using the existing SDK and signing environment. VersionCode 6301, versionName 0.5.0-ui63, same Android application ID/signing identity for upgrades. Do not publish a VARNA_DEBUG59 build.

Physical Honor 90 playback, thermal behavior and native ASR model inference quality remain separate device validation gates. Existing renderer/codec/export limitations remain; this is not CapCut feature parity.
