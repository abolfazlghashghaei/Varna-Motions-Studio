# نسخهٔ ۶۲ — نصب ساده‌تر؛ پلاگین بدون بخش تدوین

در نصب‌کننده، نام نمایشی «موتور وارنا» است. صفحهٔ اصلی مراحل قابل فهم را نشان می‌دهد و گزارش فنی پشت گزینهٔ «جزئیات فنی» قرار دارد. دکمهٔ اصلی بسته به انتخاب کاربر «نصب»، «تعمیر» یا «حذف» است. مسیرها و نام واقعی منابع در گزارش فنی و اطلاعات مجوز حفظ می‌شوند؛ تغییر نام پوشه‌های فنی موتور انجام نمی‌شود.

صفحهٔ تدوین، حالت حرفه‌ای، پنجرهٔ جدا، مسیر تولید و میانبرهای مربوط، فایل‌های JS/CSS اختصاصی و ورودی مستقل editor.html از این انتشار حذف شده‌اند. ابزار تدوین همراه Railcut دیگر با نصب پنل نصب نمی‌شود و میانبر آن در پنل وجود ندارد. باینری‌های رسانه و مجوزها که برای صدا/زیرنویس لازم‌اند باقی می‌مانند. داده‌های پروژه‌های قبلی پاک نمی‌شوند. نصب‌کننده، پنل قبلی را پشتیبان می‌گیرد و نسخهٔ جدید را جایگزین می‌کند؛ پنجرهٔ تدوین در نسخهٔ فعال جدید وجود ندارد.

کتابخانه‌های داده/رندر مشترک که متن، جدول، موشن و خروجی بومی به آن‌ها وابسته‌اند حفظ می‌شوند. نام داخلی بعضی کتابخانه‌ها تاریخی است و به معنی وجود رابط تدوین نیست. پروژه‌ها یا پلاگین‌های تدوین مستقل شخص ثالث که از قبل جدا نصب شده‌اند خودکار حذف نمی‌شوند.

رابط باقی‌مانده در Chromium واقعی آزموده شده است: صفحه و منوی تدوین، API رابط و مسیر تولید ویدیو وجود ندارند؛ متن وارد می‌شود و صفحات متن، جدول، موشن و بک‌گراند بدون خطای JS یا فایل runtime مفقود باز می‌شوند. آزمون مستقل جدول نیز گذشت. اجرای بومی Adobe و ظاهر نصب‌کننده روی Windows واقعی در محیط توسعه تأیید نشده است؛ EXE امضای تجاری ندارد.
