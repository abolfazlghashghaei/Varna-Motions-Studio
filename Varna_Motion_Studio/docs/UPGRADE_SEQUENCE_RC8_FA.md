# RC8 — اتصال اصل قالب‌های شیشه به بک‌گراند متن

- شش پروژهٔ AEP موجود در بستهٔ Max از صفحهٔ بک‌گراند وارد پروژهٔ AE می‌شوند. Composition انتخابی منبع لایهٔ زیر متن هر کپشن است؛ طراحی و افکت اصلی داخل آن حفظ می‌شود.
- محدودهٔ اعمال، اندازهٔ متناسب با متن، شفافیت، فاصله، جابجایی و تکرار/ثبات زمان قابل تنظیم‌اند. استفاده از Composition واقعی در پیش‌نمایش و خروجی مشترک است.
- جایگزینی استایل و پاک‌سازی Preview/Output لایه‌های متعلق به Varna را حذف می‌کند؛ منبع اصلی و پروژهٔ واردشده حفظ می‌شوند. نبود منبع پیش از شروع خروجی گزارش می‌شود.
- گالری مجزا برای المان مستقل، تنظیم کنترل‌های سطحی و MOGRTهای Premiere حفظ شد. استایل‌های پارامتریک اکنون با عنوان «الهام» مشخص‌اند.
- ۲۳ مجموعهٔ آزمون Node از جمله مسیر واقعی اتصال و حذف لایهٔ بک‌گراند اجرا شدند. رندر واقعی ویندوز/After Effects و Missing Footage هنوز آزمون نشده است.
- امکانات گستردهٔ باقی‌ماندهٔ متن ارتقا مانند ساخت موسیقی از ویدیو، Depth/Auto Reframe، خروجی MOGRT و Premiere Bridge هنوز پیاده‌سازی نشده‌اند؛ جزئیات در سند RC7 آمده است.
