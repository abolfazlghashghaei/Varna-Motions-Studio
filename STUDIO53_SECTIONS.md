# Studio53 — section reference and acceptance map

Scope approved by the user: AE gets the video editing workspace and all existing plugin tools. Premiere and Resolve get shared production tools only. Their installers do not install the NLE entrypoint, controller or stylesheet. This supersedes the cross-host editor scope described in Studio52.

This is an implementation/acceptance map, not a claim that a web panel has reached feature parity with Premiere, After Effects, Resolve or Final Cut. No code/assets were copied from those commercial interfaces. The dark monitor/bin/track arrangement is independently implemented.

| Section | Reference behavior | Implemented in this release | Evidence / practical limit |
|---|---|---|---|
| Host entry | Separate workspace per application | AE studio button/window/fullscreen; Premiere Motion Tools CEP; Resolve shared-tools launcher | Browser/fullscreen/handoff tests; actual Adobe/Resolve activation still unrun |
| Project / media bin | Premiere-style persistent Project pane | Import/drop/search, thumbnails, source selection, relink, cached originals, project save/recovery | Real media import; codec support depends on Chromium/CEP |
| Source monitor | Source In/Out and insert at a target track | Source play/scrub, frame timecode, In/Out, Insert/Append, source name protection | UI test checks actual resulting source trims; no source patching of separate A/V pairs |
| Program monitor | Shared composite of active tracks | Actual video/image, graphic, caption, color, mask, blend and audio preview | Pixel/real-media tests; Canvas appearance differs from native host shaders |
| Timeline layout | Source/Program/Inspector above Project/Sequence | Premiere-inspired resizable bin split; adjustable track heights; responsive compact panels | Four viewport widths tested; compact panels hide Source below 700 px |
| Playhead/ruler | Direct click and continuous mouse dragging | Coalesced seeks, frame stepping, wheel/shift-wheel navigation, zoom/fit, edge scrolling | Actual mouse drags on both ruler and moving playhead; not only API calls |
| Clip editing | Selection, Razor, Ripple, Roll, Slip, Slide | Real source/timeline transactions, source-bound checks, gap closing, drag move/trim, delete/duplicate, undo/redo | Vitest cases and mouse Razor/undo; edits operate on the selected media track, not multi-selection sync groups |
| Track management | Many ordered video/audio layers | Add video/audio tracks, target selection, mute/lock, ordered compositing | Active-interval query tested with 10,000 clips / 128 tracks; this is not a real-time 128-decoder playback benchmark |
| Marks / work area | Markers and I/O-delimited delivery | Add/jump markers, I/O, range strip, clear range, frame-aligned cuts | Export probe verifies work-area duration; no full marker metadata editor yet |
| Transport / keyboard | Accessible physical keys | Space, arrows, V/C/B/N/Y/U/A/H, I/O, comma insert, J/K/L, Shift+M, undo/save | Ignores typing targets and user's Alt shortcuts; accelerated shuttle uses muted seeks, not pitch-correct audio |
| Proxies / scenes | Lightweight preview and scene cuts | FFmpeg proxy, toggle original/proxy preview, originals for video export, scene-cut markers | Actual proxy encoded and red/blue source cut measured; proxies are session-local and must be recreated after reopening |
| Sequence settings | Common delivery sizes | HD, Full HD, DCI2K, UHD/DCI4K, portrait, square, 8K; fractional FPS fields up to120 | Document and host preflight limits agree; 8K is an allowed pixel budget, not a performance guarantee |
| Titles / transcription | Speech-aligned titles as editable graphics | Existing ASR, SRT, timed captions, title/word styles, fonts/colors/background/entry presets | Shared title renderer; real local ASR models were not run in this environment |
| Corrections / translation | Contextual suggestions with explicit review | Existing right-click AE approval flow retained; shared tools propose/approve; AE studio approves same/identical captions | Mock model tests; no silent text rewriting; shared tools do not yet duplicate every legacy word-review menu |
| Typography | Per-word appearance and entry | Fonts, color, size, position, backgrounds and motion; existing English/Persian looks | Real Canvas pixel/metadata tests; font availability is host-dependent |
| Graphics / backgrounds | Layer Size independent of Scale | Shape dimensions, fixed roundness, transforms, easing/keyframes, blends, masks, glass approximation | Width/height keys and native adapter model tested; no universal AE-native-effect runtime in browser |
| Table | One shared surface with continuous dividers | Shared table renderer, TSV, line color/width/opacity, alignment/padding, cell settings and imported merges | Existing table suites + shared-tools UI creation; full AE table controller remains in AE main panel |
| Grading | Convenient clip color controls | Exposure, brightness, contrast, saturation, hue, looks, animated properties | Render/export and native rejection checks; no Resolve node graph, managed HDR pipeline, scopes or tracking masks |
| Audio mix | Track gain/fades and visible waveform | Actual WebAudio mix/gain, fades, mute, decoded source-trimmed waveform | Real mixed export; no VST/AU chain, bus routing or loudness mastering claim |
| Sound generation / AI | One local engine flow with persistent job IDs | Kind/model/style/instrument controls; prompt-scoped WebSocket progress; history/reconnect; per-job safe cancel; persistent journal | Controlled HTTP/WS fixtures test real sockets and lost jobs; subjective generation quality/actual GPU models untested |
| Brands | Reuse approved identity/assets | Existing AE brand/assets workflow preserved; shared tools save/apply/export title styles | Shared tools currently have a style library, not full automatic host asset-pack import |
| Delivery | Named codecs, ranges, stills, alpha | WebM, H264, HEVC, ProRes422HQ, WAV24, MP3, AAC, PNG/JPEG, graphics ProRes4444 alpha, SRT, project JSON | Real FFmpeg/ffprobe all6 profiles; browser video capture is real-time/visible-window; not offline deterministic video rendering |
| Interchange | Source trims, tracks and gaps in OTIO | OTIO export/import, caption/graphics metadata, relink | Actual official OTIO0.18.1 parse/serialize round trip; rejects overlaps, nested sequences, transitions/speed effects rather than silently dropping them |
| Premiere output | Graphics on video tracks | Editable MOGRT or full-style alpha MOV; empty-range protection | ES3 SDK model tests; no subtitle track insertion; native Premiere session untested |
| Resolve output | Text+ / graphics on video tracks | Text+ settings utility or full-style alpha MOV; separate shared-tools service | Python syntax and controlled installer tests; Text+ duration requires editor trim; actual Resolve execution untested |
| Effects / vendor packs | Host-appropriate implementations | Native AE integrations retained; explicit compatibility map for Canvas/Premiere/Resolve | AE binaries are not copied into other hosts; optical glass cannot refract future host footage from an alpha overlay |
| Language / identity | English LTR and Persian RTL | Existing dictionary plus new control labels; protects user names/text; reduced repeated branding | UI language/value tests; some legacy diagnostics/model messages remain Persian |
| Reliability / diagnostics | Validate input and reveal actual work states | Zod graph/endpoint schema, PQueue request limits, Pino redacted local log, persistent job files, atomic edit rollback | Actual WS/history/cancel/lost-job fixtures; no fake timer progress or global interruption |
| Install / package | Verified complete package, staged activation | Exact source hashes, copied-file allowlist, per-host stages/backups, existing LFS restoration kept | Package verifier; portable PowerShell Resolve filesystem path test; Windows registry/host load still separate gates |

Remaining product work is recorded in the last column. Features such as multicam editing, motion tracking, GPU optical flow, temporal denoising, advanced compositing, Dolby delivery, managed HDR and third-party native effects cannot be implied by the resemblance of the workspace.
